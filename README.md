# AI勉強会 告知ページ

社内AI勉強会の告知用ランディングページです。上部に大きなデモビジュアル、下部に「タイトル」「開催日時」「場所」の3項目を配置しています。

## デモビジュアル

ページ上部には `assets/ai-workshop-visual.svg` を表示しています。ブラウザで `index.html` を開くと、告知ページ全体の完成イメージを確認できます。

## ローカル確認

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://127.0.0.1:8000/index.html` を開いてください。

## ローカル参照の一括確認

HTML の `src`・`href`・`poster` と CSS の `url(...)` が指すローカルファイルをまとめて確認できます。外部 URL とページ内リンクは対象外です。参照切れがある場合は場所を表示し、終了コード `1` を返します。

```bash
python3 scripts/check_local_assets.py
```

別のディレクトリを確認する場合は、そのパスを引数に渡してください。
